# 型の分類

Wiki ページの 	ype は、内容の話題ではなく知識上の役割で選ぶ。

| 役割 | 型 | 用途 |
| --- | --- | --- |
| 統合された知識 | concept | 分かったことをまとめる |
| 出典 | paper、rticle、documentation など | ソースが主張する内容を記録する |
| 推論結果 | query-result | 調査や照会の結論を記録する |
| 構造 | section | 関連ページをまとめる |
| 作業手順 | skill | エージェント用の手順を記録する |
| 参照資料 | doc | 仕様書などを記録する |

ブログ記事で学術研究を扱っていても、型は paper ではなく rticle とする。
